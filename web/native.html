Repopulated Native multiplayer alpha

Two players fly separate ships in one host campaign using Reassembly's native controls and HUD. Each faction explores separately by default; the host can enable shared exploration below.

This experimental alpha uses stock ships and a private two-seat campaign. The native maps show the same galaxy data in discovered areas. Remote building, full progression, mod loading and exploration beyond the host's loaded sectors remain unfinished. Use the desktop launcher for saving and resuming galaxies.
